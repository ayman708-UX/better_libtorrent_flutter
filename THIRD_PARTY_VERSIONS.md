# Third-Party Dependencies

This document tracks the pinned versions/commits for all submodules in the `third_party/` directory to ensure reproducible builds. When upgrading dependencies, bump the versions here and in the corresponding git submodule tag.

- **libtorrent**: `v2.1.1` (https://github.com/arvidn/libtorrent)
- **boost**: `boost-1.87.0` (https://github.com/boostorg/boost)
- **openssl**: `openssl-3.3.2` (https://github.com/openssl/openssl)
- **libdatachannel**: `v0.22.0` (https://github.com/paullouisageneau/libdatachannel)
